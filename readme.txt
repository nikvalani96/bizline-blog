BizLine Blog is a clean, responsive WordPress block theme designed for modern business blogs, personal brands, and corporate publications with full site editing support.

== Description ==

BizLine Blog is a clean, responsive, and highly flexible WordPress block theme built for modern business blogs, personal brands, and corporate publications. With full support for the block editor and full site editing (FSE), it helps organizations share insights, case studies, and news in a clean, professional layout.

**Perfect For:**
* Business blogs
* Corporate websites
* News publications
* Personal brands
* Professional portfolios
* Company announcements
* Industry insights sharing

== Installation ==

1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Type in "BizLine Blog" in the search form and press the 'Enter' key on your keyboard.
3. Click on the 'Activate' button to use your new theme right away.
4. Navigate to Appearance -> Editor to customize your site using the Site Editor.

**Manual Installation:**
1. Download the theme zip file
2. Go to Appearance -> Themes -> Add New -> Upload Theme
3. Choose the downloaded zip file and click Install Now
4. After installation, click Activate

== Frequently Asked Questions ==

= Does this theme support full site editing? =

Yes! BizLine Blog is built specifically for WordPress's full site editing feature, giving you complete control over your site's design.

= Is the theme responsive? =

Absolutely! BizLine Blog is fully responsive and looks great on all devices, from mobile phones to desktop computers.

= Can I customize the colors? =

Yes, the theme includes custom color options that you can adjust through the Site Editor or Customizer.

= Does the theme support widgets? =

Yes, BizLine Blog supports both classic widgets and block-based widgets in the footer area.

= What page builders are supported? =

BizLine Blog is built for WordPress's native block editor (Gutenberg) and full site editing. It works best with WordPress's built-in editing tools.
